# Excel-Dashboard
Amazon Sales Analysis Dashboard built using Microsoft Excel. Features include sales analysis, category and brand performance, monthly trends, order status, payment methods, top 10 cities and products, and country-wise sales analysis using Pivot Tables, Pivot Charts, and Slicers.



# Amazon Sales Analysis Dashboard 📊

# Project Overview
This project is an interactive Amazon Sales Analysis Dashboard created using Microsoft Excel. It focuses on analyzing sales data and presenting important business information through charts, reports, and visualizations.

# Project Objectives
- Analyze overall sales performance.
- Understand sales by product category and brand.
- Identify monthly sales trends.
- Analyze order status and payment methods.
- Identify top-performing cities and products.
- Explore country-wise sales performance.

# Excel Skills Used
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Analysis
- Dashboard Design
- Data Visualization

- Dashboard
